DIY First

先自己花 3 分钟排查一下

常见问题里，有不少其实自己就能搞定。点开看看，不行再来找我。

开机要等一两分钟

按 Ctrl + Shift + Esc 打开任务管理器 →「启动」标签，把不需要开机自启的程序右键禁用（尤其是各种助手、更新器）。再用 Win + R 输入 %temp% 清理临时文件。

如果还是慢多半是机械硬盘，换一块固态（¥200–¥400）开机可进 15 秒内，我上门 30 分钟装好。

蓝屏 / 自动重启

蓝屏画面左下角有一串代码（如 MEMORY_MANAGEMENT、CRITICAL_PROCESS_DIED），拍下来发我。若频繁出现，先看是否刚装过新软件/驱动，最近是否断电或搬动过主机。

判断方向内存条接触不良、硬盘坏道、驱动冲突最常见。远程我可以读事件日志定位，硬件问题则需上门检测。

WiFi 老是掉线、网速慢

先用手机站在路由器旁边测速对比：手机快、电脑慢，是电脑网卡/驱动问题；两边都慢，是宽带或路由器问题。路由器断电 30 秒再上电，能解决一大半。

如果还慢可能是信道拥挤或路由器老旧，我可以远程帮你改信道、或上门调整位置/更换设备。

打印机打不出来 / 共享不了

先看「设置 → 蓝牙和其他设备 → 打印机和扫描仪」里打印机是否显示「脱机」。脱机就重启 Print Spooler 服务；共享失败多半是两台电脑不在同一网段或未开启文件共享。

如果还乱驱动装错版本最常见，远程我 15 分钟内一般能配好一台共享打印。

弹窗广告关不掉、浏览器被改

打开任务管理器看可疑进程的「打开文件位置」，把不明软件卸载；再检查浏览器扩展与主页锁定。很多弹窗来自「高速下载器」捆绑安装。

根治建议这类捆绑常驻自启、互相拉起，手动删不干净。远程我清理自启项 + 计划任务 + 装轻量防护，一般 30 分钟搞定。

文件误删了 / 硬盘打不开

立刻停止往这块盘写入任何东西（别下载、别安装恢复软件到同一块盘）。回收站有就直接还原；没有的话恢复成功率取决于是否被覆盖。

重要硬盘有异响（咔哒声）不要反复通电，先做镜像再恢复。数据恢复 ¥199 起，先检测报价，恢复不出来不收费。

C 盘满了、电脑提示空间不足

用 设置 → 系统 → 存储 看占用大头；清理「临时文件」「以前的 Windows 安装」；把微信/QQ 的文件保存路径改到 D 盘，往往能一次性释放几十 GB。

更彻底可以无损扩容 C 盘（需 D 盘有空间），远程可做，¥99 起。

电脑没声音 / 麦克风没反应

右下角音量图标 → 确认输出设备选对了（别选到显示器或蓝牙耳机）；再在「声音设置」里做设备测试。笔记本常见是驱动被系统更新替换。

如果还不行重装声卡驱动即可，远程 10 分钟处理。
